TeeRabbit Quote Calculator

Google Sheets Setup Guide  ·  Version 1.0

This guide walks you through setting up your Google Sheet so the Quote Calculator can read your pricing, garments, and settings. The sheet stays in your Google Drive — you own it, you update it, and changes go live automatically.

Step 1  —  Make a copy of the template

Open the shared template link and go to File → Make a copy. Save it anywhere in your Google Drive. Give it a name you'll recognize (e.g. Acme Print Shop — Quote Calculator).

Step 2  —  Share the sheet publicly

The calculator reads your sheet directly from Google's servers. For this to work, the sheet must be set to Anyone with the link → Viewer.

How to do it: Click the blue Share button (top right) → click Change to anyone with the link → make sure it says Viewer → click Done.
Is this safe? "Anyone with the link" means only people who have your specific link can see it — it is not listed in Google Search. Your sheet only contains pricing and garment data, the same information customers see in the calculator.

Step 3  —  Copy your Sheet ID

Your Sheet ID is the long string of letters and numbers in the URL between /d/ and /edit:

https://docs.google.com/spreadsheets/d/1H4GSOZJAFsVJUs31-O7ftsPHjmRRdAZJdTjmfkfDtD0/edit

Copy that highlighted section — that is your Sheet ID. You'll enter it during signup.

Settings Tab

Two columns only: key in column A, value in column B. The key names must be spelled exactly as shown.

Important — row order matters: Put contact_email and contact_phone as the first two rows, before any numeric rows. Google's export silently drops text values if numbers come first. This is a known Google Sheets limitation.

Screen Print Tiers Tab

This is your price grid. Rows = ink colors. Columns = order quantities. Each cell is the print cost per shirt for that combination.

Column headers (Row 1)

The first column must be labeled Colors. Each subsequent column header is just the quantity number — no labels, no "pcs" suffix.

Row labels (Column A)

Just the number — 1, 2, 3, not "1 Color" or "1-color". The calculator reads the number directly.

Prices

Dollar signs and commas are fine — the parser strips them. Decimals are supported.

Flexibility: You can have as few as 2 quantity columns and 1 color row — the calculator adapts to whatever you enter. Columns must go left to right in ascending order. Rows must go top to bottom in ascending order.
Do not leave cells blank or enter $0.00 in the middle of your grid. A blank or zero cell will show customers a $0 price for that combination. Only omit trailing columns/rows you don't offer.

Garments Tab

One row per garment. Row 1 must be the column headers exactly as shown below.

Column nameDescription & allowed values
name Required Full display name shown to customers. E.g. Gildan 5000 Heavy Cotton Tee
brand Required Brand name. E.g. Gildan, Bella+Canvas, Next Level
id Required Style number. E.g. G5000, BC3001
apparel_type Required Must be exactly one of: T-Shirt  Hoodie  Tank Top  Long Sleeve  Crewneck  Polo
gender Required Must be exactly one of: Unisex  Women's  Youth  Kids
tier Required Must be exactly one of: Budget  Standard  Premium
base_price Required Your blank garment cost. Numbers only — no dollar sign. E.g. 4.50
live Optional Leave blank to show the garment. Enter FALSE to hide it without deleting the row.

Brand Rules Tab

Optional. Forces all garments from a specific brand into a fixed tier, overriding whatever is in the tier column. Useful if you always want Bella+Canvas to show as Premium regardless of how it's entered.

Column nameDescription
brand_or_style Brand name exactly as it appears in your Garments tab. Case-insensitive.
forced_category Must be one of: Budget  Standard  Premium

If you don't need this, leave the tab empty — but keep the tab in your sheet. The calculator expects it to exist even if it has no data rows.

Quick Reference — Common Issues

ProblemLikely cause
Contact email / phone not showing Move those rows above the numeric rows in the Settings tab
Garment not appearing in the calculator Check live column isn't set to FALSE. Check apparel_type and gender spelling exactly matches the allowed values.
Pricing shows as $0.00 A cell in Screen Print Tiers is blank or zero. Fill in the actual price.
Calculator not loading at all Sheet sharing is not set to "Anyone with the link". Check Share settings.
Price changes not showing up Google caches the sheet data for a short time. Wait a few minutes and hard-refresh the page (Ctrl+Shift+R).
